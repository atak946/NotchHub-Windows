## New

- Setup assistant: on first launch it introduces the features and asks for the basic settings, privacy choices, permissions and SteelSeries Sonar profile switching. You can reopen it from the tray menu or from Settings → Genel.

If you are updating from an earlier version, the assistant does not open by itself.

The app's interface is in Turkish. The executable is not code-signed with a Windows certificate, so SmartScreen may warn on first launch.
