First public release.

## Highlights
- A notch panel for Windows: media with lyrics, audio mixer, calendar, system status, devices, timer, clipboard history, file tray, notes and notification history.
- SteelSeries Sonar: pick a GAME profile from the panel, or let it switch automatically for calls, games, music and idle time.
- Updates come from GitHub Releases and are installed only when their signature verifies.

The app's interface is in Turkish. The executable is not code-signed with a Windows certificate, so SmartScreen may warn on first launch.
