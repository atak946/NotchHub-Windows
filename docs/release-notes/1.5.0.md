## New

- **NotchSetup.exe**: an installer that puts Notch in your user folder (no administrator rights), adds a Start menu shortcut and an entry in Windows' installed apps list. You can remove it from there.
- An About page (Settings → Hakkında) with the version, the developer (Murat ATAK), GitHub profile and project links.

`Notch.exe` is still published for portable use. Installed copies keep updating themselves; you do not need to run the installer again.

The app's interface is in Turkish. The files are not code-signed with a Windows certificate, so SmartScreen may warn on first launch.
