## Fixed

- The game overlay's FPS reading no longer jumps around. It is now calculated from the timestamps of the frame events instead of the number of events that arrive each second.

**If you use the FPS helper:** it does not update by itself. Open Settings → Oyun, choose **Kaldır** and then **Etkinleştir (yönetici izni)**.

## Updated

- Audio library (NAudio.Wasapi 2.4.0) and the event tracing library used for FPS (TraceEvent 3.2.8).

The app's interface is in Turkish. The executable is not code-signed with a Windows certificate, so SmartScreen may warn on first launch.
